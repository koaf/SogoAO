### 4つの方式のうち、どれを選ぶ？

関西学院大学の総合型選抜には探究活動や国際交流、競技実績などを伝えられる方式があります。どれを選ぶかで出願条件や準備する資料が変わります。

高校で取り組んできた探究活動、国際的な活動、英語資格、リーダーシップ経験、スポーツ実績などをもとに受験生の資質や学ぶ意欲を多面的に評価する入試です。

方式は主に次の4つです。

- 探究評価型入学試験
- グローバル入学試験
- 学部特色入学試験
- スポーツ選抜入学試験

方式を選ぶときは**自分の経験と出願要件が合うか**を確かめます。活動の名前だけで決めず、志望学部で受けられる方式を調べましょう。

## 1. 関西学院大学の総合型選抜とは

関西学院大学の総合型選抜は受験生がこれまでに培ってきた基礎学力、活動経験、資質、能力、学ぶ意欲、人間性などを多面的に評価する入試です。

一般選抜では主に教科試験の得点が重視されます。
一方で総合型選抜では書類、活動実績、資格、面接、小論文、プレゼンテーションなどを通して受験生の考え方や将来性が見られます。

### 総合型選抜で見られやすいポイント

| 評価される力 | 具体的に見られること |
|---|---|
| 目的意識 | なぜ関西学院大学で学びたいのか |
| 探究心 | 高校時代にどんなテーマに取り組んできたか |
| 主体性 | 自分から行動した経験があるか |
| 表現力 | 書類・面接・小論文で考えを伝えられるか |
| 基礎学力 | 入学後の学びに必要な学力があるか |
| 将来性 | 大学での学びを将来にどうつなげたいか |

資格や大会実績が条件の方式ではそれを満たす必要があります。条件を確かめたら、自分が取り組んだことと学部で学びたい内容を整理していきましょう。

## 3. 関西学院大学の総合型選抜は4種類ある

関西学院大学の総合型選抜には主に4つの方式があります。

| 入試方式 | 活かしやすい経験・強み |
|---|---|
| 探究評価型入学試験 | 高校での探究活動、発表経験 |
| グローバル入学試験 | 国際的な活動、英語資格、国際交流経験 |
| 学部特色入学試験 | 学部に合った経験、英語資格、リーダーシップなど |
| スポーツ選抜入学試験 | 高校入学後のスポーツ実績 |

どの方式も、「関西学院大学で学びたい」という意欲が前提になります。

そのうえでどの方式が自分に合っているかを考える必要があります。

## 4. 探究評価型入学試験とは

探究評価型入学試験は高校での探究活動を活かしやすい入試です。

関西学院大学の公式ページでは探究評価型について全14学部で実施される入試として紹介されています。

### 探究評価型に向いている人

- 高校の授業で探究活動に取り組んだ
- 課題研究やプロジェクト学習を行った
- 学校内外で探究活動を発表した経験がある
- 自分でテーマを決めて調査・分析・発表した
- 探究活動を大学での学びにつなげたい

探究の経験はテーマ名を挙げるだけでは伝わりません。次の順で説明してみてください。

1. なぜそのテーマに関心を持ったのか
2. どのように調査・活動したのか
3. どんな発見や課題があったのか
4. その経験から何を学んだのか
5. 関西学院大学でどう深めたいのか

### 探究活動の伝え方

| NG | OK |
|---|---|
| 「学校の探究授業で地域課題について調べました」 | 「商店街の来街者減少に関心を持ち、店舗への聞き取りと高校生向けアンケートを行い、若者向けイベントの提案をまとめました」 |
| 「発表を頑張りました」 | 「調査結果をもとに、課題・原因・改善案を整理し、学年発表会で発表しました」 |
| 「環境問題に興味があります」 | 「校内の食品ロス調査を行い、廃棄量の記録と原因分析から、購買方法の改善案を考えました」 |

結果に加えて、調べ方を選んだ理由や途中で考えを変えた所も話せるようにしておきます。

## 5. グローバル入学試験とは

グローバル入学試験は国際的な活動や英語資格を活かしやすい入試です。

「グローバル」と聞くと長期留学をしていないと出願できないと思う人もいるかもしれません。
しかし、関西学院大学の公式ページでは海外留学経験がなくても出願できることが示されています。

### グローバル入学試験に向いている人

- 海外留学や語学研修に参加した
- 国際交流活動に参加した
- 国内で国際交流や多文化交流に関わった
- 英語資格を持っている
- 国際問題や異文化理解に強い関心がある
- 将来、国際的な分野で活動したい

国際的な活動は海外経験だけではありません。

たとえば国内での国際交流、地域の外国人支援、多文化共生に関する活動、国際ボランティア、オンライン交流なども、条件に合えばアピール材料になります。

### グローバル系の志望理由で大切なこと

「英語が好き」と思う理由や、その力を使って知りたいことを考えてみましょう。

次のように経験と学びたいテーマをつなげましょう。

| NG | OK |
|---|---|
| 「英語が得意なので国際系に進みたいです」 | 「地域の国際交流イベントに参加し、言語だけでなく文化的背景を理解する重要性を感じました。大学では多文化共生について学びたいです」 |
| 「海外に興味があります」 | 「短期語学研修で、同じ社会問題でも国によって考え方が違うことに気づき、国際関係を多角的に学びたいと考えました」 |

英語資格は大切ですが資格だけで合格が決まるわけではありません。
交流の中で気になったことや、自分で調べた内容をメモしておくと書類作成にも使えます。

## 6. 学部特色入学試験とは

学部特色入学試験は学部ごとに求める人物像や出願条件が異なる入試です。

関西学院大学の公式ページでは学部特色入学試験は12学部で実施されると紹介されています。

### 学部特色入学試験に向いている人

- 受験したい学部がはっきり決まっている
- その学部で学びたい理由を具体的に説明できる
- 英語資格や活動実績がある
- リーダーシップを発揮した経験がある
- 学部の学びと高校時代の経験がつながっている

学部特色入学試験を考えるなら志望学部の授業や研究を調べてみてください。自分の経験から何を学びたくなったかを説明します。

たとえば同じボランティア経験でも、学部によって伝え方は変わります。

| 志望学部 | 経験のつなげ方の例 |
|---|---|
| 社会学部 | 地域やメディア、社会課題への関心につなげる |
| 法学部 | ルール、公共性、制度、社会問題への関心につなげる |
| 経済学部 | 地域経済、格差、消費行動、政策への関心につなげる |
| 商学部 | ビジネス、マーケティング、組織運営への関心につなげる |
| 人間福祉学部 | 福祉、支援、共生社会への関心につなげる |
| 教育学部 | 子ども、学校、教育課題への関心につなげる |
| 総合政策学部 | 地域課題、政策、環境、国際社会への関心につなげる |

学部特色入学試験を受ける人はまず志望学部のアドミッション・ポリシーを読みましょう。
そのうえで自分の経験がどのように学部の学びにつながるかを整理することが大切です。

## 7. スポーツ選抜入学試験とは

スポーツ選抜入学試験は高校入学後のスポーツ活動において、優れた能力や競技実績を持つ人を対象とした入試です。

関西学院大学の公式ページではスポーツ選抜は全14学部で実施されるとされています。

### スポーツ選抜に向いている人

- 高校入学後に競技実績がある
- 部活動やクラブチームで継続的に競技に取り組んだ
- 競技力だけでなく学業にも取り組む意欲がある
- 大学入学後も競技やチーム活動に貢献したい
- スポーツ経験を将来の学びや進路につなげたい

スポーツ選抜では競技実績が重要です。
ただし面接や書類では競技結果だけでなくそこから何を学んだかも問われやすいです。

競技結果以外では次の点も整理しておきます。

- 目標達成のためにどう努力したか
- ケガや不調をどう乗り越えたか
- チームの中でどのような役割を果たしたか
- 競技経験を大学でどう活かしたいか
- 学業と競技をどう両立したいか

## 8. 併願に関する重要な注意点

関西学院大学の総合型選抜では併願について特に注意が必要です。

### 総合型選抜内での併願はできない

関西学院大学の総合型選抜では同一年度内に複数の総合型選抜へ出願することはできません。

例えば次のような出願はできません。

- 探究評価型とグローバル入学試験を両方受ける
- 学部特色入学試験で複数の学部に出願する
- 同じ年度内に別の総合型選抜へ再出願する

出願できるのは**1つの入学試験・1つの学部・学科・課程・専修・コースのみ** です。

### 合格した場合は入学が条件

関西学院大学の総合型選抜は関西学院大学を第一志望とする受験生を対象としています。

そのため合格した場合は入学することが条件です。

> 注意：総合型選抜は「とりあえず受けておく入試」ではありません。出願前に本当に関西学院大学で学びたいのか、志望学部で何を学びたいのかをしっかり確認しましょう。

### 不合格後の一般選抜は可能

総合型選抜で不合格になった場合でも、関西学院大学の一般選抜に出願することは可能です。

ただし同一年度内に別の総合型選抜へ出願することはできません。

| 方式 | まず準備したいこと |

### 志望理由書で意識したい流れ

志望理由書では次の流れを意識すると書きやすくなります。

1. 関心を持ったきっかけ
2. 高校時代に取り組んだこと
3. その経験から見えた課題や学び
4. 関西学院大学の志望学部で学びたいこと
5. 入学後に取り組みたいこと
6. 将来どのように活かしたいか

「関学に入りたい」と思ったきっかけを書いたらそこで学びたい内容を加えます。授業や研究の説明を読むと自分の関心との接点を探せます。

## 11. よくある失敗と注意点

### 失敗1：方式選びをなんとなく決める

関西学院大学の総合型選抜は方式によって評価される経験が違います。

探究活動を活かしたいのか、国際経験を活かしたいのか、学部の特色に合った経験を伝えたいのか。
まずは自分の強みを整理してから方式を選びましょう。

### 失敗2：証明資料の準備が遅れる

活動実績や資格をアピールする場合、客観的な資料が必要になることがあります。

必要になる資料の例です。

- 賞状
- 資格証明書
- 活動証明書
- 発表資料
- 顧問や担任による証明
- 新聞記事や活動記録

資料がない場合、評価対象にならない可能性もあります。
早めに学校の先生へ相談しておきましょう。

### 失敗3：志望理由が抽象的すぎる

「校風に惹かれた」と書いたらどの場面でそう感じたかを加えてみます。大学で学びたい内容の説明も忘れないようにしましょう。

次のように自分の経験と学部の学びをつなげましょう。

| NG | OK |
|---|---|
| 「関西学院大学の雰囲気が好きです」 | 「探究活動で地域の外国人支援について調べた経験から、多文化共生について学びたいと考えました」 |
| 「国際的な大学なので志望しました」 | 「国際交流活動を通じて、文化の違いによる誤解に関心を持ち、国際社会におけるコミュニケーションを学びたいと考えました」 |
| 「リーダーシップがあります」 | 「部活動で練習メニューの改善を提案し、チーム内で役割分担を見直した経験があります」 |

### 失敗4：第一志望である理由を説明できない

関西学院大学の総合型選抜は第一志望であることが前提です。

書類や面接では、次の3点を説明できるようにします。

- なぜ関西学院大学なのか
- なぜその学部なのか
- 入学後に何をしたいのか

## 13. 受験体験談を募集しています

WABI-LABでは関西学院大学の総合型選抜を受験した方の体験談を募集しています。

面接で聞かれたことや志望理由書で工夫したことなど、実際の準備や試験の話はこれから受験する高校生の参考になります。

合格した方だけでなく不合格だった方、合否待ちの方の体験も歓迎しています。
準備で困ったことや、後からやっておけばよかったと思うことも教えてください。

### 募集している内容

- 受験した学部・学科
- 選考内容
- 面接で聞かれたこと
- 小論文やプレゼンのテーマ
- 志望理由書で意識したこと
- 準備を始めた時期
- やってよかった対策
- 後輩へのアドバイス

個人名、高校名、受験番号、面接官の名前など、個人が特定される情報は公開しません。

[総合型選抜の体験談アンケートに協力する](https://docs.google.com/forms/d/e/1FAIpQLSfHbVMK0HMYN2XFa4zpOJAPT5McIZBjRAlodCspg63ZLHltWg/viewform?usp=publish-editor)

## 出願要件と自分の経験を照らし合わせる

関西学院大学の総合型選抜には探究評価型、グローバル、学部特色、スポーツ選抜の4つの方式があります。

それぞれ評価される経験や強みが異なるためまずは自分が高校時代に取り組んできたことを整理しましょう。

- [ ] 探究活動を活かしたいなら探究評価型
- [ ] 国際的な活動や英語資格を活かしたいならグローバル入学試験
- [ ] 志望学部に合った経験を伝えたいなら学部特色入学試験
- [ ] スポーツ実績を活かしたいならスポーツ選抜入学試験

気になる方式を一つ選び、出願資格と提出資料を確認してみてください。用意できる資料がわかったら先生に相談し、書類作成と試験対策の予定を立てましょう。
