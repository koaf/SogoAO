## 1. 京都府立大学の推薦は、志望学科の条件から確認する

「京都府外の高校からでも出願できる？」「評定はどれくらい必要？」「共通テストは受けるの？」。京都府立大学の学校推薦型選抜を調べるときは、まず志望学科を決め、その学科の出願資格・推薦条件・試験内容を確認しましょう。

2027年度の学校推薦型選抜では、5学部12学科で計165人を募集します。出身学校長の推薦が必要で、合格した場合に入学を確約できる人が対象です。栄養科学科は大学入学共通テストを利用し、それ以外の学科は利用しません。出典：[大学公式・学校推薦型選抜](https://www.kpu.ac.jp/admissions/exam/guide/recommendation/)、[2027年度学生募集要項・11〜14、20ページ](https://www.kpu.ac.jp/media/R9_gakkousuisen_youkou_0826.pdf)。

この記事は、2027年4月入学に向けて、2026年秋以降に行われる入試の紹介です。「2027年度入試」と「2027年秋に受ける入試」を取り違えないようにしてください。

### この記事でわかること

- 府内・全国・系属高校枠の違いと学科別の募集人数
- 評定、履修科目、学校ごとの推薦人数で確認すること
- インターネット登録と書類郵送、それぞれの締切
- 小論文・総合問題・面接・テーマ作文の準備方法

> 情報確認日：2026年10月25日。大学公式の2027年度募集要項（8月26日訂正版）に基づいています。出願前には、公式ページに追加の変更や訂正がないか確認してください。本文の準備方法や練習例は、編集部からの提案です。

## 2. 府内・全国枠と、12学科の募集人数

### 京都府外の高校からでも、全国枠で出願できる

「府内」の対象には、京都府内の高校を2027年3月に卒業見込みの人などが含まれます。京都府外の高校でも、本人または保護者（親権者）が2026年4月1日から引き続き京都府内に居住していれば、府内の資格に該当する場合があります。この場合は住民票による証明が必要です。

「全国」は、所在地を問わず、高校を2027年3月に卒業見込みの人などが対象です。全国枠には府内の出願者も含まれます。専修学校高等課程などの扱いを含め、正確な資格は[募集要項12ページ](https://www.kpu.ac.jp/media/R9_gakkousuisen_youkou_0826.pdf)で確認してください。

系属高校枠は、大学が定めた系属高校での連携学習などを条件とする枠です。また、農学生命科学科と森林科学科には、対象分野の専門教育を受けた高校生向けの特別枠があります。いずれも、一般の府内・全国枠とは条件を分けて確認します。

2027年度は、文学部・社会科学部で推薦の募集人数が増えています。農学生命科学科・森林科学科では系属高校枠による増員があるため、前年度の人数をそのまま使わず、[2027年度の入学者選抜情報](https://www.kpu.ac.jp/admissions/exam/guide/)を参照してください。

## 3. 評定だけでなく、履修科目と校内の推薦条件を確かめる

### 全学共通の「評定平均○以上」は示されていない

2027年度募集要項の推薦条件には、多くの学科で「成績優秀な者」と記載されています。全学共通の数値として「評定平均4.0以上」などを掲げているわけではありません。評定平均とは、高校の各科目の評定を平均した値で、調査書では「全体の学習成績の状況」として扱われます。

数値による一律の条件が書かれていなくても、学校長の推薦は必要です。出願を考えたら、担任や進路指導の先生に、現在の成績、学校の推薦方針、校内選考の締切を確認してください。大学への出願期間より、校内の締切が早い場合があります。

### 学科ごとの追加条件

次の表は、主な履修条件を整理したものです。「修得」には修得見込みの単位数も含まれます。学校ごとの推薦上限や例外を含む原文は、[募集要項13ページ](https://www.kpu.ac.jp/media/R9_gakkousuisen_youkou_0826.pdf)で確認できます。

| 対象 | 確認する推薦条件 |
| --- | --- |
| 文学部の3学科 | 成績優秀で、外国語12単位以上を修得していること |
| 公共政策学科・福祉社会学科 | 成績優秀で、外国語12単位以上を修得していること |
| 農学生命科学科・和食文化科学科 | 成績優秀であること |
| 栄養科学科 | 成績優秀で、理科12単位以上を修得していること |
| 生命化学科 | 成績優秀で、「化学基礎・化学」を履修していること |
| 理工情報学科 | 数学・理科の条件を満たし、成績優秀、または指定の検定・国家試験に合格していること |
| 森林科学科・環境デザイン学科 | 成績優秀であること |

理工情報学科は、高校の学科によって数学・理科の条件が異なります。普通科では「数学Ⅲ」と理科12単位以上の修得が条件です。情報科学科、工業科等には別の条件があるため、自分の教育課程に対応する欄を読みましょう。

指定の検定・国家試験は、英検2級以上または基本情報技術者試験です。検定等に合格していても、数学・理科の履修条件は満たす必要があります。証明書類の提出方法も募集要項で確認してください。

### 高校が推薦できる人数にも上限がある

大学全体の募集人数と、高校が推薦できる人数は別です。例えば、文学部は各学科について全日制・定時制・通信制の各課程から3人以内、公共政策学科・福祉社会学科は各課程から2人以内です。森林科学科は推薦人数の制限を設けていません。

公共政策学科・福祉社会学科・理工情報学科では、高校の科目名が学習指導要領の名称と異なる場合に「読替協議」が必要です。これは、高校で学んだ科目を大学の指定科目として認められるか、学校を通じて事前に確認する手続きです。

2027年度の協議期間は2026年8月24日〜9月28日で、この記事の公開時点では終了しています。該当しそうな場合は、学校で承認済みかどうかを先生に確認してください。出典：[大学公式・事前協議](https://www.kpu.ac.jp/admissions/exam/guide/recommendation/)。

## 4. 出願登録は10月26日から、書類受付は11月1日から

### ネット登録と郵送では、受付開始日も締切時刻も異なる

2027年度の出願は、インターネット登録、入学考査料等の支払い、学校長による書類郵送の順に進めます。**インターネット登録だけでは出願は完了しません。** 学校が発送する時間を確保して予定を立てましょう。

| 手続き・試験 | 日程 |
| --- | --- |
| インターネット出願登録 | 2026年10月26日（月）9時〜11月9日（月）正午 |
| 出願書類の郵送受付 | 2026年11月1日（日）〜11月9日（月）17時必着 |
| 大学での試験 | 2026年11月28日（土） |
| 合格発表（栄養科学科以外） | 2026年12月10日（木）正午 |
| 入学手続日（栄養科学科以外） | 2026年12月25日（金） |
| 合格発表（栄養科学科） | 2027年2月10日（水）正午 |
| 入学手続日（栄養科学科） | 2027年2月17日（水） |

出典：[大学公式・出願手続](https://www.kpu.ac.jp/admissions/exam/internet/)、[大学公式・試験等の日程](https://www.kpu.ac.jp/admissions/exam/guide/recommendation/)。書類が期限後に到着した場合は、11月8日（日）までの消印がある書留速達郵便に限り受け付けるとされています。例外に頼らず、学校と必着に間に合う発送日を決めてください。

### 出願前に、本人と学校の担当を分けて確認する

1. 志望学科・出願区分・推薦条件を先生と確認する。
2. 本人がインターネットで登録し、入学考査料等を支払う。
3. 必要書類を印刷し、志望理由書や学校が作成する書類と合わせて学校へ提出する。
4. 学校長が書類を取りまとめ、大学へ書留速達で郵送する。

共通して必要な主な書類は、出願確認票、写真票、受験票、推薦書、調査書です。志望理由書は理工情報学科を除く学科で必要になり、理工情報学科・森林科学科はテーマ作文も提出します。該当者には住民票や検定試験の証明書類なども必要です。出典：[募集要項15〜18ページ](https://www.kpu.ac.jp/media/R9_gakkousuisen_youkou_0826.pdf)。

支払い後に印刷できる書類があるため、学校への書類提出日を先に相談しておくと、登録後の作業を進めやすくなります。入力・支払い・印刷を出願最終日にまとめる計画は避けましょう。

## 5. 学科別の試験内容と、栄養科学科の共通テスト

### 面接の有無も、筆記試験の種類も学科で異なる

推薦書・調査書などに加えて、何を受験するかを下表に整理しました。書類を含む選抜方法の詳細は、[募集要項14ページ](https://www.kpu.ac.jp/media/R9_gakkousuisen_youkou_0826.pdf)に掲載されています。

| 学科 | 大学で受ける主な試験 | 共通テスト |
| --- | --- | --- |
| 日本・中国文化学科 | 日本語・英語の文章や資料に基づく小論文 | 利用しない |
| 国際文化交流学科 | 英語の文章や資料に基づく小論文 | 利用しない |
| 歴史学科 | 英語の文章・資料に基づく総合問題、日本語の文章・資料に基づく小論文 | 利用しない |
| 公共政策学科・福祉社会学科 | 小論文 | 利用しない |
| 農学生命科学科 | 総合問題、面接 | 利用しない |
| 栄養科学科 | 小論文、面接 | 利用する |
| 和食文化科学科 | 総合問題 | 利用しない |
| 生命化学科 | 総合問題、面接 | 利用しない |
| 理工情報学科 | 面接（出願時にテーマ作文を提出） | 利用しない |
| 森林科学科 | グループディスカッション、面接（出願時にテーマ作文を提出） | 利用しない |
| 環境デザイン学科 | 総合問題、面接 | 利用しない |

総合問題とは、学科が求める知識や理解力、思考力などを問う試験です。学科によって出題内容が異なるため、[大学公式の過去問題](https://www.kpu.ac.jp/admissions/exam/past/)から志望学科の問題と解答例・出題意図を確認してください。

### 栄養科学科は、共通テスト6教科8科目が必要

栄養科学科の受験生は、11月の大学での小論文・面接に加え、大学が指定する共通テストを受験します。募集要項20ページの配点では、共通テストが1,000点、大学側の選抜が400点、合計1,400点です。

指定は、国語、地理歴史・公民から1科目、数学2科目、理科2科目、英語、情報Ⅰの6教科8科目です。理科は「物理・化学・生物」から2科目、英語はリスニングを含みます。地理歴史・公民の選択可能科目と第1解答科目の扱いも確認が必要です。指定科目を1科目でも受験しない場合、選抜対象になりません。出典：[募集要項20ページ](https://www.kpu.ac.jp/media/R9_gakkousuisen_youkou_0826.pdf)。

さらに、共通テスト成績請求チケットを別途提出します。公式の出願手続ページでは、12月4日以降に郵送し、提出期限は2026年12月18日（金）とされています。初回の出願書類とは別の手続きとして、予定表に記入しましょう。出典：[大学公式・成績請求チケットの郵送](https://www.kpu.ac.jp/admissions/exam/internet/)。

## 6. 志望理由書・作文・筆記・面接の準備方法

### 志望理由書は、経験と大学で学びたいことをつなぐ

志望理由書は、本人が志望動機と自己PRを600字程度にまとめる指定です。理工情報学科は提出対象に含まれません。農学生命科学科・栄養科学科・森林科学科では、裏面の「大会成績・受賞実績」も記載します。出典：[募集要項17ページ](https://www.kpu.ac.jp/media/R9_gakkousuisen_youkou_0826.pdf)。

下書きでは、「関心を持った経験」「そこから生まれた疑問」「入学後に学びたい内容」を並べてみてください。次の表は書き方の練習例で、合格者の文章や大学の指定表現ではありません。自分にない経験を借りず、実際に取り組んだ内容で考えましょう。

| 抽象的な書き方 | 具体化する方向 |
| --- | --- |
| 「京都が好きなので歴史を学びたい」 | 調べた地域や史料、調べてもわからなかった疑問を書き、大学で学びたい研究方法につなげる |
| 「地域社会に貢献したい」 | 関わった活動と、その中で気づいた制度・政策上の課題を説明する |
| 「環境問題を解決したい」 | 森林・住居・建築など、どの対象の何を調べたいのかを絞る |

学科のアドミッション・ポリシーは、大学が求める学生像や選抜方針を示したものです。募集要項の冒頭に掲載されています。自分の関心に合う点を確かめ、授業や研究分野の情報も大学公式サイトで確認してから書いてください。

文章の組み立てを練習したい人は、[志望理由書の書き方ガイド](https://wabi-lab.blog/posts/shibou-riyuusho-kakikata/)も参考にできます。大学指定の様式・字数は京都府立大学の要項を優先しましょう。

### 理工情報学科・森林科学科は、出願前のテーマ作文が必要

理工情報学科は、学科サイトで提示された課題図書を読み、要約と、それに関連する自分の考えや思い描く未来を書く課題です。指定用紙に横書き・自筆で4,000字以内とされています。森林科学科は、持続可能な社会における科学について考えるテーマで、指定用紙に横書き・自筆で1,200字以内です。正式な課題文は[募集要項17ページ](https://www.kpu.ac.jp/media/R9_gakkousuisen_youkou_0826.pdf)で確認してください。

作文は出願時に提出するため、11月28日の試験に向けた勉強とは別に締切を設けます。読書や資料確認、構成、下書き、清書に必要な日数を見積もり、学校への提出日から逆算してください。

理工情報学科の練習では、図書の内容を説明する部分と、自分の意見を述べる部分を区別して書くと、引用元の考えと自分の考えが混ざっていないか確認できます。

### 小論文・総合問題は、志望学科の過去問から始める

文学部では、英語の文章や資料を読む準備が必要です。公共政策学科・福祉社会学科の小論文は150分です。農学生命科学科などの総合問題は、学科が求める基礎知識も問われます。試験時間は[募集要項19ページ](https://www.kpu.ac.jp/media/R9_gakkousuisen_youkou_0826.pdf)で確認できます。

練習は、過去問を解き、解答例や出題意図と照らして、足りなかった知識と読解上の誤りを分けて記録する方法をすすめます。「自分の意見を多く書けたか」より、設問に答え、資料を正確に扱えているかを先生と確認しましょう。

### 面接は提出書類とのつながりを、討論は相手の発言の理解を練習する

面接を課す学科では、自分の提出書類を読み返し、経験の経緯、疑問、大学で学びたい内容を説明する練習をしましょう。以下は編集部が提案する練習用の問いで、実際の出題を予告するものではありません。

- なぜその出来事や問題に関心を持ったのか。
- 調べた内容からわかったことと、まだわからないことは何か。
- 自分の考えに別の見方があるとしたら、どう答えるか。
- 入学後は、どの分野をどのように学びたいか。

森林科学科のグループディスカッションは、複数人で意見を交わす試験です。練習では、相手の意見を短く確認してから、自分の賛成点や疑問を理由とともに述べてみてください。発言の回数だけを目標にすると、相手の話を聞く時間を取りにくくなります。

受け答えの準備には、[面接での伝え方を比較する記事](https://wabi-lab.blog/posts/mensetsu-goukaku-hikaku/)も利用できます。

## 7. 併願・入学手続きまで確認して、先生に相談する

### 合格した場合は、入学することが前提

出願資格として、合格した場合に京都府立大学へ入学する確約が求められます。大学公式FAQでも、特別な事情がない限り入学辞退はできないと説明されています。他大学の推薦や総合型選抜との併願は、その大学の要項も確認してください。

本学や他の国公立大学の一般選抜に出願することはできます。ただし、学校推薦型選抜に合格して入学手続きを完了した場合、国公立大学の前期・中期・後期日程を受験しても合否判定の対象になりません。出典：[大学公式FAQ・学校推薦型選抜](https://www.kpu.ac.jp/admissions/faq/)。

### 出願前のチェックリスト

- [ ] 入学年度が2027年度であることを確認した。
- [ ] 志望学科と、府内・全国・系属高校・特別枠の該当条件を確認した。
- [ ] 履修科目・単位数と、高校からの推薦が可能かを先生に確認した。
- [ ] 校内選考と学校への書類提出の締切を把握した。
- [ ] インターネット登録・支払い・学校からの郵送を予定に入れた。
- [ ] 指定様式で志望理由書やテーマ作文を準備した。
- [ ] 栄養科学科は、共通テストの指定科目と成績請求チケットの提出を確認した。
- [ ] 合格後の入学手続日を家族と共有した。

今日できることは、公式の募集要項で志望学科の条件を読み、履修科目がわかる資料を持って先生に相談することです。そのうえで、学校への書類提出日と大学の試験日から逆算し、作文・筆記・面接の準備を予定表に書き込みましょう。
