## 1. 京大特色入試では何が求められる？

京都大学の入試を調べると「特色入試」という言葉を目にします。一般選抜とは異なる枠組みとして高校現場や受験生の間では「京大推薦」「京大特色」と呼ばれています。国際大会のメダリストや特別な研究実績を持つ人しか受からないのかと不安に感じる受験生も多いのではないでしょうか。

京都大学の特色入試は、高等学校での学修における高い学力と個々の学部の特性に応じた**卓越した能力・探究心・学ぶ意欲**を多面的に評価する入試制度です。全10学部で実施されており、学部によって「総合型選抜」または「学校推薦型選抜」に分かれています。

選考では提出書類（特に京大独自の「学びの設計書」）に加え、小論文や口頭試問などの第2次選考、そして大学入学共通テストが課されます。突出した肩書だけでなく「高校時代に何を深め、なぜ京大で研究したいのか」を論理的に説明できる資質が強く問われます。

この記事では2027年度（令和9年度）の公式募集要項をもとに全10学部の選考構造、独自書類「学びの設計書」の書き方、合格者に共通する特徴、一般選抜と両立する準備法を具体的に整理します。

### この記事でわかること

- 2027年度京大特色入試の全体像と「総合型」「学校推薦型」の区分
- 学部別（文系・理系・医療系）の選抜方式と第2次選考の内容
- 京大名物「学びの設計書」の書き方とNG・OK例
- 共通テストのボーダー目安（概ね8割〜85%）と医学部の例外措置
- どんな人が受かるのか（合格者の資質とよくある誤解）
- グループA・グループBの日程と高1・高2・高3の準備ロードマップ

## 2. 京大特色入試の仕組み｜全10学部の選抜区分と日程グループ

### 総合型選抜と学校推薦型選抜の2本立て

京都大学の特色入試は全学部共通の画一的な試験ではありません。学部・学科の教育理念に応じて「総合型選抜」と「学校推薦型選抜」のいずれかを採用しています。

学校長からの推薦が必要な「学校推薦型選抜」を実施するのは、法学部・経済学部・医学部医学科・工学部の4区分です。その他の総合人間学部・文学部・教育学部・理学部・医学部人間健康科学科・薬学部・農学部は、学校長推薦を必須としない「総合型選抜」の枠組みで出願を受け付けます。

なお従来法学部で実施されていた一般選抜の後期日程は2025年度入試より廃止され、特色入試の学校推薦型選抜（募集人員20名）へ完全に統合されました。

| 学部 | 選抜区分 | 募集人員の目安 | 主な出願要件・選考要領 |
| --- | --- | --- | --- |
| 総合人間学部 | 総合型選抜 | 5人（文系3・理系2） | 調査書・学業活動報告書・学びの設計書、能力測定考査、共通テスト |
| 文学部 | 総合型選抜 | 10人 | 調査書・学びの設計書、論述試験・論文試験、共通テスト |
| 教育学部 | 総合型選抜 | 5人（文系4・理系1） | 評定要件あり、調査書・学びの設計書、課題・口頭試問、共通テスト |
| 法学部 | 学校推薦型選抜 | 20人 | 学校長推薦、英語資格、小論文試験、共通テスト |
| 経済学部 | 学校推薦型選抜 | 25人（文系19・理系6） | 学校長推薦、調査書・学びの設計書、論文試験、共通テスト |
| 理学部 | 総合型選抜 | 15人程度（女性枠あり） | 分野別選抜、学びの報告書、数理考査・口頭試問、共通テスト |
| 医学部 医学科 | 学校推薦型選抜 | 5人 | 学校長推薦（高評定）、TOEFL等、口頭試問・面接（共通テスト点数不問） |
| 医学部 人間健康科学科 | 総合型選抜 | 10人（看護6・リハ4） | 調査書・学びの設計書、面接（口頭試問含む）、共通テスト |
| 薬学部 薬科学科 | 総合型選抜 | 4人 | 調査書・学びの設計書、課題論文・面接、共通テスト |
| 工学部 | 学校推薦型選抜 | 39人程度（女性枠あり） | 学校長推薦、各学科専門口頭試問・面接、共通テスト |
| 農学部 | 総合型選抜 | 29人程度 | 調査書・学びの設計書、小論文・面接・口頭試問、共通テスト |

※募集人員および実施詳細は年度によって微修正される場合があります。必ず最新の公式要項を確認してください。

### グループAとグループBに分かれる選考日程

特色入試の出願と試験日程は、大きく**グループA**と**グループB**の2つに分かれています。

- **グループA（理学部、医学部人間健康科学科など）**：10月上旬に出願を受け付け、11月上旬に第1次選考合格発表、11月中旬に第2次選考を実施します。
- **グループB（上記以外の8学部）**：11月上旬に出願を受け付け、11月下旬に第1次選考合格発表、12月上旬〜中旬に第2次選考を実施します。

志望学部がどちらのグループに属しているかを把握しておかないと出願書類の作成や高校との連絡が間に合わなくなります。特にグループAを志望する受験生は夏休み終了と同時に出願書類を完成させるペースで進めなければなりません。

### 共通テスト「概ね8割〜85%」の重み

京大特色入試の合否判定において、共通テストは極めて重要です。書類や2次試験でどれほど高い評価を得ても、共通テストで学部が指定する基準（概ね80%〜85%以上など）に届かなければ最終合格者にはなれません。

ただし**医学部医学科**は例外です。医学部医学科では出願要件として共通テストの指定教科・科目を受験する必要がありますが、共通テストの得点は最終的な合否判定に利用されません。提出書類と第2次選考（口頭試問・面接）の実力で合否が決まるため、1月下旬という異例の早さで最終合格発表が行われます。

医学部医学科を除く9学部では、特色入試を受ける場合でも一般選抜と同等水準の教科の学力対策が前提となります。

## 3. 学部別の選抜方式一覧｜2次試験と求める資質

### 文系学部の選考ポイント

文系学部（総合人間学部文系、文学部、教育学部文系、法学部、経済学部文系）では、高度な読解力、社会や人間に対する深い問題意識、論理的に自説を組み立てる記述力が問われます。

| 学部・区分 | 第2次選考の内容 | 求める人物像と対策の着眼点 |
| --- | --- | --- |
| 総合人間学部（文系） | 能力測定考査（文系総合問題） | 既存の学問領域にとらわれず人間と文明の課題を多角的に分析できる思考力 |
| 文学部 | 「学びの設計書」に関する論述試験・論文試験 | 提出した設計書の内容を掘り下げる論述試験と人文学の課題論文。文章読解力と自己の批評眼 |
| 教育学部（文系） | 課題および口頭試問 | 教育や人間形成の諸問題に対する関心と対話の中で思考を発展させる柔軟性 |
| 法学部 | 小論文試験（英語文章を題材とする日本語論述） | 英語文献の要所を的確に把握した上で法的・政治的・社会的な問いに対して論理を展開する力 |
| 経済学部（文系型） | 論文試験 | 現代の社会・経済課題に関するデータや文章を読み解き数理的または論理的に論述する力 |

特に法学部は英語の長文を題材にした小論文が課されるため、一般的な英語読解力に加えて論理構成を素早く日本語で再構築する訓練が欠かせません。文学部では「学びの設計書」に関する論述試験が課され、自分が高校時代に読んだ文献や探究内容についてその場での深い論述が求められます。

### 理系・医療系学部の選考ポイント

理系・医療系学部（理学部、工学部、農学部、薬学部、医学部、総合人間学部理系、教育学部理系、経済学部理系型）では、教科書レベルを超えた自然科学への探究心と数学・理科の論理的運用能力が試されます。

| 学部・区分 | 第2次選考の内容 | 求める人物像と対策の着眼点 |
| --- | --- | --- |
| 理学部 | 数学・理科の筆記考査、口頭試問 | 数理科学、物理、宇宙地球、化学、生物の各系で大学レベルの課題に食らいつく発想力と論理的説明力 |
| 工学部 | 各学科の口頭試問・面接 | 地球工学、建築、物理工学、電気電子、情報、工業化学での専門的適性と物理・数学の深い理解 |
| 農学部 | 小論文、面接・口頭試問 | 食料・生命・環境・森林などの課題に対する明確な問題意識と基礎的な科学的思考力 |
| 薬学部（薬科学科） | 課題論文、面接 | 創薬科学や生命科学の実験・研究に対する強い意欲と論理的な考察力 |
| 医学部（医学科） | 口頭試問、面接 | 生命科学への深い探究実績、MD-PhDコース（研究医）を志す明確な動機と高い倫理観 |

理学部の口頭試問では黒板を使って試験官の前で自分の思考プロセスを説明する形式が採用されます。公式を当てはめて答えを出すのではなく「なぜその手法を選んだのか」「反例はないのか」といった試験官からの鋭い問いかけに対処できるかが合否の分かれ目となります。

工学部や理学部では女子枠（女性募集枠）が設置されている学科もあり、理工系分野で活躍を目指す女子生徒への門戸が広がっています。

## 4. 京大独自書類「学びの設計書」の書き方と評価ポイント

### なぜ志望理由書ではなく「設計書」と呼ばれるのか

他大学の推薦入試では「志望理由書」や「自己推薦書」という名称が一般的ですが、京都大学では**「学びの設計書」**という独自の名称が使われています。

単に「京大に入りたい熱意」や「過去の自慢実績」を書き連ねる書類ではありません。**「高校までの学びや体験を通じてどのような問題意識を持ち、京都大学の当該学部で具体的に何をどのように学び、将来社会でどう展開していくのか」**という未来の学修計画を論理的に設計する文書です。

大学側はこの書類を通じて、受験生が自律的に研究テーマを設定し、主体的に探究を進められる人物かどうかを見極めています。

### 典型的な構成と設問

学部によって指定様式や文字数は異なりますが、共通して問われるのは以下の3本柱です。

1. **高校在学中の探究活動や学業の成果（400〜600字程度）**  
   教科の学習、探究活動、課外活動、読書体験などからどのような問いを持ち、どう主体的に深めたか。
2. **当該学部に入学して何を学びたいか・研究したいテーマ（600〜800字程度）**  
   大学のカリキュラムや研究環境を踏まえ、どの講義や演習、研究室でどのような課題を追求したいか。
3. **卒業後の進路や将来の展望（200〜400字程度）**  
   大学での学びを土台として、将来どのような研究者、専門家、または社会人として貢献したいか。

### NG例とOK例の比較

| NG例：抽象的・受け身な記述 | OK例：具体的・主体的な設計 |
| --- | --- |
| 「京大の自由の学風に憧れ、幅広い教養を身につけたいです」 | 「〇〇という現象に疑問を持ち、△△の視点から先行文献を比較した。貴学の□□研究室が扱う解析手法を習得し、課題を解明したい」 |
| 「高校時代にボランティア活動をたくさん頑張りました」 | 「地域の水質調査を行う中で、法定基準と住民の実感の乖離に着目した。環境経済学の視点から政策評価の手法を学びたい」 |
| 「世界的に有名な〇〇教授の講義を受けたいです」 | 「現在取り組んでいる〇〇の課題では△△の理論が壁になっている。貴学が開講する『□□論』でモデル化の手法を学び検証を進めたい」 |

文章の論理構成を磨く基本ルールは[志望理由書の書き方ガイド](https://wabi-lab.blog/posts/shibou-riyuusho-kakikata/)でも解説しています。京大の学びの設計書では大学のパンフレットの言葉をコピーするのではなく「自分の関心の延長線上に京大の学びがある」という接続を丁寧に言葉にしましょう。

### 第2次選考の口頭試問・面接は設計書から深掘りされる

「学びの設計書」は書類審査を通過するための道具にとどまりません。第2次選考の面接や口頭試問、あるいは文学部の論述試験において**試問の土台**として徹底的に利用されます。

面接官を務める大学教授陣は、提出された設計書を精読した上で次のような本質的な質問を投げかけてきます。

- 「高校で読んだと書かれているこの論文の著者の前提条件には、どんな批判がありますか」
- 「大学で〇〇を研究したいとのことですが、なぜ他大学の△△学部ではなく京大のこの学科なのですか」
- 「あなたの提案する実験手法では、〇〇の影響を排除できないのではないですか」

背伸びをして専門用語を羅列しただけの設計書を作ると口頭試問で即座に見抜かれます。自分が本当に理解し、検証した事実をもとに自分の言葉で語れる内容で作成することが不可欠です。

面接官とのやり取りや受け答えの作法については[面接での伝え方を比較する記事](https://wabi-lab.blog/posts/mensetsu-goukaku-hikaku/)も役立ちます。

## 5. どんな人が受かる？合格者に共通する特徴と誤解

### 誤解1：「国際大会の受賞歴がないと受からない？」

京大特色入試の理学部や医学部では国際科学オリンピック（数学、物理、化学、生物、情報）の出場者や受賞者が合格するケースが確かにあります。そのため「突出したコンテスト実績がなければ出願しても無駄だ」と思い込んでいる受験生が少なくありません。

しかし募集要項を精読すると、多くの学部ではコンテストの実績そのものを必須条件にしていません。重視されるのは「何を疑問に思い、どんな本を読み、どう調べ、どこまで考え抜いたか」という**思考の深さと自走力**です。

身近な自然観察から疑問を深めた人、地域の課題を独自の統計分析で考察した人、古典の原典比較に没頭した人など、自発的な探究を粘り強く積み重ねてきた生徒が多数合格しています。肩書の大きさよりも「研究に対する誠実な問い」を持っているかどうかが本質です。

### 誤解2：「特色入試なら共通テストや一般選抜の勉強はサボれる？」

推薦や総合型というと「学科試験を免除されて楽に合格できる裏技」と誤解されることがあります。しかし京大特色入試に関しては完全に逆です。

前述のとおり医学部医学科を除く全学部で大学入学共通テストが課され、要求水準は一般選抜の合格者層と大差ない80%〜85%前後に設定されています。さらに第2次選考では京大の二次試験と同等以上の難易度を誇る論文試験や口頭試問が課されます。

つまり京大特色入試の合格者は「探究活動の実績がある人」である以前に、**「京大一般選抜を突破できるだけの教科の学力を高い水準で維持している人」**なのです。

### 合格者に共通する3つの特徴

| 特徴 | 具体的な姿 | 対策で意識すること |
| --- | --- | --- |
| 1. 自走する探究心 | 指示された課題研究だけでなく、自発的に専門書を読み、実験や観察を繰り返している | 自分の関心分野に関する専門書や学術論文に手を伸ばしてみる |
| 2. 批判的思考と対話力 | 自分の結論に満足せず「本当にそうか」「反例はないか」を疑い、助言を吸収できる | 面接練習で厳しい指摘を受けたときに反論ではなく論点整理で返答する |
| 3. 盤石な教科基礎学力 | 探究活動に時間を使いながらも、模試や定期テストで崩れない学力を保っている | 探究と共通テスト対策のスケジュールを週単位で厳格に分離する |

### 落ちた場合の一般選抜併願対策

特色入試の合格発表はグループBの最終発表が2月10日です。もし不合格だった場合、その約2週間後には国公立大学一般選抜の前期日程（2月25日・26日）が控えています。

国公立大学の出願期間は1月下旬〜2月上旬であり、特色入試の結果が出る前に一般選抜の出願手続きを済ませておく必要があります。特色入試に出願した段階で「不合格になっても一般選抜の前期日程で京大を受験する」という出願戦略を高校側と共有しておきましょう。

国公立大学全体の推薦・総合型制度や併願ルールについては[国公立大学の学校推薦型選抜ガイド](https://wabi-lab.blog/posts/kokkouritsu-gakkou-suisen-guide/)で詳しく整理しています。東京大学の推薦入試と比較検討したい方は[東大推薦の選考内容と対策記事](https://wabi-lab.blog/posts/tokyo-university-school-recommendation/)もあわせてご覧ください。

## 7. 今日から始める「問いの言語化」

京大特色入試に合格するために最も大切なのは、特別な賞を集めることではありません。「自分はなぜこの学問に惹かれ、何を明らかにしたくて、なぜ京大でなければならないのか」を、他者に納得してもらえる論理と言葉で語れるようになることです。

出願を考えている高校生が、今日まず始めるべきアクションは以下の3つです。

1. **最新の学生募集要項をダウンロードする**：志望学部のページを開き、出願要件、選抜方法、指定書類の様式を印刷して線を引きながら読む。
2. **自分の「探究の棚卸し」を1枚のメモにする**：高校時代に最も深く考えた疑問を1つ選び、「きっかけ・調べた方法・わかった事実・残った疑問」を箇条書きにする。
3. **担任または進路指導の先生に相談する**：学校推薦型・総合型のどちらで出願を検討しているかを伝え、校内手続きや今後の学習計画について話し合う。

メモを書いてみて言葉に詰まった部分は、あなたが大学で学ぶべきテーマそのものです。日常の疑問を大切にし、教科の学習と並行して自分だけの問いをじっくりと深めていきましょう。
