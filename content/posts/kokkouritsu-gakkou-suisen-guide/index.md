## 1. 最初に読むのは志望学科の募集要項

国公立大学の推薦を調べると「評定はいくつ必要？」「共通テストは受けるの？」と気になることが出てきます。その答えは志望学科と方式によって変わります。

国公立大学にも学校推薦型選抜を実施する大学・学部があります。ただし同じ大学の中でも、学部や学科によって必要な成績、試験、出願できる人の条件が変わります。受験する年度の募集要項を開き、**志望学科の出願条件と選考方法**を確認しましょう。

また学校から推薦を受けることと大学に合格することは別です。高校の推薦を得たうえで、大学が定めた選考を受けます。「推薦なら学科の勉強を減らせる」と決めつけず、必要な準備を確認しましょう。

以下では学校に相談することと出願までに準備することを順に説明します。

### この記事でわかること

- 学校推薦型選抜と総合型選抜・一般選抜の違い
- 評定、履修科目、地域要件などの確認方法
- 共通テストを課す方式と課さない方式の違い
- 併願、入学確約、一般選抜への備え方
- 校内選考から出願までの予定と具体的な対策

> 情報確認日：2026年10月25日。制度の説明は文部科学省、国立大学協会、大学公式の情報を参照しています。2027年度入試は2027年4月入学に向けて2026年中から行われる選抜を含みます。出願時には対象年度の募集要項と訂正情報を確認してください。本文の練習例・学習計画は編集部からの提案です。

### 学校長の推薦に基づき、大学が選考する入試

学校推薦型選抜は出身高校の校長による推薦を受け調査書などを用いて大学が評価する入試です。調査書とは成績や学校での活動などを高校が記載する書類です。

文部科学省の実施要項では出願書類だけで判断するのではなく学力や思考力などを評価する方法も組み合わせるとしています。志望先が何をどの方法で評価するかを読みましょう。出典：[文部科学省・令和9年度大学入学者選抜実施要項「第3 入試方法」](https://www.mext.go.jp/content/20260529-mxt_daigakuc02-000005144_1.pdf)。

| 選抜方式 | 出願・選考の基本 | 準備で確認すること |
| --- | --- | --- |
| 学校推薦型選抜 | 学校長の推薦が必要。調査書と大学が指定する試験等で評価 | 推薦条件、校内選考、必要な学力、入学意思 |
| 総合型選抜 | 本人の意思で出願し書類や面接等を通じて総合的に評価 | 出願資格、学問への関心、経験と学修計画 |
| 一般選抜 | 学力検査や小論文等を主な資料として評価 | 必要科目、配点、出題内容、受験日程 |

どの方式でも学力の確認はあります。方式名だけで難しさを比べず、必要な試験や課題に自分が取り組めるか考えてみてください。総合型選抜の基本は[総合型選抜の制度と対策ガイド](https://wabi-lab.blog/posts/sougata-senbatsu-guide/)でも説明しています。

## 2. 評定だけでは決まらない、出願条件と校内選考

### 「評定平均はいくつ必要？」は志望学科ごとに調べる

評定平均は高校の科目の評定を平均した値を指す言葉です。募集要項や調査書では「全体の学習成績の状況」などの表現が使われます。全教科の平均に加え、特定教科の成績を確認する場合もあります。

全国の国公立大学に共通する「この数値があれば出願できる」という基準はありません。志望先の推薦要件に数値があるか、対象となる教科や期間は何かを確かめましょう。数字だけでなく履修した科目や修得単位が条件になることにも注意が必要です。

例えば京都府立大学の2027年度学校推薦型選抜には学科によって外国語や理科の単位数、数学などの履修条件があります。一律の評定だけで判断できない具体例です。出典：[京都府立大学・学校推薦型選抜の募集要項](https://www.kpu.ac.jp/admissions/exam/guide/recommendation/)。

次の表を使って自分が出願を考えている方式の条件を書き出してください。

| 確認項目 | 募集要項で読む内容 | 相談・確認すること |
| --- | --- | --- |
| 卒業時期 | 卒業見込みのみか、既卒者も対象か | 自分の卒業年度が対象に入るか |
| 成績 | 全体・教科別の学習成績の条件 | 学校が作成する調査書で条件を満たせるか |
| 履修科目 | 必要な科目、単位数、修得見込みの扱い | 学校の教育課程や履修予定と合うか |
| 地域要件 | 本人・保護者の住所、高校の所在地等 | 基準日と証明書類を満たせるか |
| 資格・活動 | 必須の資格や実績、提出できる資料 | 有効期限や証明方法は何か |
| 推薦人数 | 高校や課程ごとの人数制限 | 校内の希望者数、選考方法、締切 |
| 入学意思 | 合格した場合の入学確約等 | 学び・費用・通学や転居を家族と確認したか |

条件がある項目は大学によって異なります。該当しない欄には「指定なし」と記録すると調べ忘れと区別できます。

### 大学の出願条件と高校の推薦基準を分けて確認する

大学の条件を満たしても高校の推薦が自動的に得られるとは限りません。大学が高校ごとの推薦人数を定めている場合などは校内選考が必要になります。校内選考とは高校内で推薦する人を決める手続きです。

まず担任や進路指導の先生に「この大学・学科の学校推薦型選抜を検討しています」と伝えましょう。そのうえで校内の申込期限、必要書類、面談や選考の予定を聞きます。大学の出願日だけを予定表に入れると高校側の締切に間に合わないおそれがあります。

相談には募集要項と成績・履修科目がわかる資料を持っていきましょう。「推薦で行けますか」だけでなく「この履修条件を満たしますか」「学校への申込はいつですか」と具体的に尋ねてください。

### 地域枠は名称よりも対象者の定義を読む

地域に関係する枠では本人の居住地、高校所在地、保護者の住所など、何を基準とするかが重要です。「県内出身だから対象」「県外の高校だから対象外」と自己判断しないようにしましょう。

京都府立大学の2027年度選抜には府内・全国などの区分があります。全国枠には府内の出願者も含まれるため「全国＝府外の人だけの枠」ではありません。出典：[京都府立大学・学校推薦型選抜](https://www.kpu.ac.jp/admissions/exam/guide/recommendation/)。

地域要件に加えて卒業後の進路や勤務に関する条件がある枠を検討するときはその内容も確認します。入学後の学びと将来の選択に関わるため本人と家族で募集要項や関連資料を読んでおきましょう。

## 3. 共通テストを課す方式・課さない方式の違い

### 共通テストの有無で、準備する内容と期間が変わる

大学入学共通テストは大学入試センターが実施する試験です。学校推薦型選抜でも、その成績を利用する方式があります。**学校推薦型選抜だから共通テストが不要とは限りません。**

例えば熊本大学の公式ページでは学校推薦型選抜Ⅰを「大学入学共通テストを課さない」方式として案内しています。一方京都府立大学の栄養科学科は共通テストを利用します。出典：[熊本大学・入学者選抜要項・学生募集要項](https://www.kumamoto-u.ac.jp/nyuushi/gakubunyushi/gakuseibosyuyoukoutou)、[京都府立大学・入学者受入れの方針](https://www.kpu.ac.jp/guidance/policy/admission-policy/)。

「推薦Ⅰ」「推薦Ⅱ」といった名称の意味を、別の大学にもそのまま当てはめないでください。名称の横にある説明と選抜方法の欄を読むことが大切です。

| 比較する点 | 共通テストを課す方式 | 共通テストを課さない方式 |
| --- | --- | --- |
| 学科の勉強 | 指定教科・科目と配点に合わせた対策が必要 | 個別試験、口頭試問、小論文等の内容を確認 |
| 書類・面接等 | 共通テストの準備と並行して取り組む | 大学が指定する課題に合わせて取り組む |
| 合格発表 | 共通テスト後になるため年を越す | 年内の場合もあるが大学の日程を確認 |
| 手続き | 共通テストの出願・成績提供の手続きも確認 | 推薦の出願手続きと一般選抜への備えを確認 |

### 科目数だけでなく配点と判定方法まで読む

共通テストを利用する場合は「国語・数学・英語が必要」といった大まかな理解で止めず、科目名と選択条件を一つずつ確認します。理科や地理歴史・公民の選び方、英語リスニング、情報の扱いなども確認対象です。

次に共通テストと大学での試験の配点を比較しましょう。得点を合計するのか一定の基準を設けるのか二段階で選抜するのかによって準備が変わります。必要科目の受験漏れを防ぐため学校の先生と出願内容を照合してください。

大学への推薦出願と共通テストへの出願は別の手続きです。推薦の試験が終わってからでは共通テストの申込に間に合わない場合があるため先に両方の締切を確認しておきます。

### 共通テストなしでも、基礎学力の準備は必要

口頭試問とは教科の知識や考え方などを口頭で答える試験です。面接という名称でも、志望理由だけでなく学習内容の説明を求められる場合があります。

過去問を見たら、「答えを知っているか」と「理由や解き方を説明できるか」を分けて確認しましょう。理科なら実験結果の読み取り、数学なら解法の根拠、英語なら文章の要点説明など、志望先の形式に合わせて練習します。

## 4. 併願と入学確約は出願前に確認する

### 国立大学の推薦は複数校への出願を前提にしない

併願とは複数の大学や選抜方式に出願することです。国立大学協会のFAQでは国立大学の学校推薦型選抜の出願者について、他の国公立大学の学校推薦型選抜への出願はできず、出願は一つの大学・学部に限ると説明しています。

例外として同じ大学・学部の同じ募集単位で、共通テストを課さない推薦に不合格となった後、共通テストを課す推薦に出願できる場合があります。別の学科や別大学に自由に出し直せるという意味ではありません。出典：[国立大学協会・入試FAQ Q4](https://www.janu.jp/exam/adm_faq/)。

公立大学を志望する場合も、複数校に出せると自己判断せず各大学の募集要項で制限を確認してください。私立大学との併願についても双方の出願資格と入学確約の条件を読む必要があります。

### 「合格したら入学する」という条件を軽く考えない

国立大学協会は学校推薦型選抜の合格者は入学することを前提とし、特別の事情による辞退には学校長からの所定の手続きと大学の許可が必要と説明しています。出典：[国立大学協会・入試FAQ Q7](https://www.janu.jp/exam/adm_faq/)。

そのため出願前に確認したいのは合格の可能性だけではありません。学部で学べる内容、卒業後の進路、学費、生活費、通学や転居を含めて、その大学に進学する意思を固めましょう。

保護者には費用や住居の見通しを一緒に確認してもらいましょう。志望理由は本人が考えて書きます。合格発表日と入学手続期限も家族で共有してください。

### 一般選抜への準備は続けておく

国立大学協会のFAQでは学校推薦型選抜への出願後も国公立大学の一般選抜への出願・受験は可能としています。ただし推薦に合格して入学手続きを完了すると一般選抜を受験しても合格者にはなれません。出典：[国立大学協会・入試FAQ Q3](https://www.janu.jp/exam/adm_faq/)。

推薦の結果を待っている間に一般選抜の出願期限が来ることもあります。推薦が不合格だった場合の受験先、必要科目、出願締切も予定表に入れておくと結果を待つ間の勉強を進めやすくなります。

総合型選抜との併願については国立大学協会が一律に可否を定めているわけではありません。両方の大学・方式の条件を確認しましょう。出典：[国立大学協会・入試FAQ Q6](https://www.janu.jp/exam/adm_faq/)。

## 5. 校内選考から入学手続きまでのスケジュール

### 高校の締切と大学の締切を一つの予定表に入れる

2027年度の文部科学省の実施要項では学校推薦型選抜の入学願書受付は2026年11月1日以降、合格発表は12月1日以降とされています。これは全国的な枠組みであり、各大学の実際の受付期間や試験日は別途確認が必要です。出典：[文部科学省・令和9年度大学入学者選抜実施要項「第4 試験期日等」](https://www.mext.go.jp/content/20260529-mxt_daigakuc02-000005144_1.pdf)。

以下は準備の目安です。高3の秋に検討を始めた人は校内選考に間に合うかを先生に確認し、残り期間で必要な作業を組み直しましょう。

| 時期の目安 | 取り組むこと | できあがっているとよいもの |
| --- | --- | --- |
| 高1・高2 | 授業・探究に取り組み、関心のある分野を調べる | 活動や疑問、読んだ資料の記録 |
| 高3の春〜夏 | 大学を調べ、推薦条件と校内の手続きを確認 | 志望候補の条件比較表 |
| 募集要項の公表後 | 出願条件、必要科目、試験、日程を再確認 | 対象年度の確認表と予定表 |
| 校内選考前 | 学校指定の申込や面談、書類準備を進める | 校内提出用の書類 |
| 大学への出願前 | 指定様式で作成し、登録・支払い・提出を確認 | 提出書類一式と手続きの控え |
| 出願後〜試験 | 過去問、面接、必要な教科学習を続ける | 添削や練習で見つかった課題の記録 |
| 合格発表後 | 入学手続き、または一般選抜の予定に対応 | 必要な提出・納付の完了記録 |

### インターネット登録だけで出願完了と思わない

出願には登録、検定料の支払い、書類提出など複数の作業があります。本人が郵送するのか、学校が取りまとめるのかも確認してください。推薦書や調査書は学校が作成するため発行に必要な日数を見込むことが大切です。

「必着」は期限までの到着が必要で、「消印有効」は指定された日までの郵便局の消印を基準とします。どちらが適用されるか、時刻の指定はあるかを募集要項で確かめましょう。

予定表には大学の最終締切だけでなく下書き提出、先生の確認、清書、学校への提出、発送の予定を書きます。修正できる時間を残すと書類を落ち着いて確認できます。

### 推薦と教科学習を両立する時間を決める

書類を毎日少しずつ直し続けると終わりが見えにくくなります。「今週は構成を先生に見てもらう」「次は経験の説明を直す」と、作業ごとの区切りを設けましょう。

平日は教科学習の時間を先に確保し、書類の修正は時間を決めて取り組む方法もあります。共通テストを課す方式では模試や過去問の結果も確認し、推薦対策に時間を使いすぎていないかを定期的に見直してください。

## 6. 志望理由書・小論文・面接の準備とよくある失敗

### 志望理由書は経験から生まれた問いを具体化する

最初に読むのは志望先のアドミッション・ポリシーです。これは大学がどのような力や意欲を持つ学生を求め、どう評価するかを示す方針です。続いて授業や研究分野を調べ、自分の関心とのつながりを整理します。

下書きは「経験」「気づいた問題」「自分で調べたこと」「大学で学びたいこと」の順でメモすると進めやすくなります。受賞歴の大きさだけを探すより授業や探究、部活動などで、自分が何を考えて取り組んだかを振り返ってみてください。

実績や資格が必須の方式ではその条件を満たすことが先です。文章の工夫だけでは出願条件を補えません。

以下は具体化の方向を示す練習例です。自分が実際に経験した内容に置き換えてください。

| NG例：説明が抽象的 | OK例：経験と学びがつながる |
| --- | --- |
| 「地域に貢献したいです」 | 「通学に使うバスの減便を調べ、住民の移動を支える政策に関心を持ちました」 |
| 「理科が得意だから志望します」 | 「探究で水質を測定し、測定条件で値が変わる理由を化学の視点で学びたいと考えました」 |
| 「貴学の教育に魅力を感じます」 | 「自分の問いと関連する授業・実習を挙げ、そこで身につけたい方法を説明します」 |

大学のパンフレットの表現を並べるだけでは自分の関心が伝わりにくくなります。「なぜ自分にその学びが必要なのか」を加えましょう。詳しい構成は[志望理由書の書き方ガイド](https://wabi-lab.blog/posts/shibou-riyuusho-kakikata/)も参考にできます。

### 小論文は設問と資料を正確に読むことから

小論文の練習では最初に志望先の過去問を確認します。課題文や図表を使うのか、英語を読むのか、教科の知識が必要かを調べましょう。一般的な作文練習だけでは形式に対応しきれない場合があります。

1. 設問の指示を確認し、答えるべき点に印をつける。
2. 資料の要点と自分の意見を分けてメモする。
3. 結論と根拠を組み立て、時間を測って書く。
4. 先生の添削を受け、設問への答え方と読み違いを直す。

例えば「資料を踏まえて原因を説明する」という設問に、対策だけを書いても十分な回答になりません。練習後は文字数だけでなく求められた内容に答えているかを確認してください。

### 面接は暗記よりも質問に合わせて説明する練習

面接を課す方式では提出書類を読み返し、書いた経験や学びたい内容を自分の言葉で説明します。友人や先生に追加質問をしてもらうと説明が曖昧な部分に気づけます。

練習用の問いとしては「なぜその問題に関心を持ったか」「調べてわかったことと、まだわからないことは何か」「別の見方をするとどう考えられるか」などが使えます。これは実際の出題を予告するものではありません。

経験を大きく見せようとせず自分の役割と他の人の役割を分けて説明しましょう。知らないことを聞かれたら、無理に断定せずわかる範囲と考える手順を伝える練習も役立ちます。

### よくある失敗は条件と準備を混同すること

| よくある失敗 | 防ぐための行動 |
| --- | --- |
| 評定の条件を満たしたので安心する | 履修科目、校内推薦、大学の選考内容まで確認する |
| 前年度の募集要項だけで準備する | 対象年度の要項、変更予告、訂正情報を読む |
| 推薦なら年内に進路が決まると思う | 共通テストの有無と合格発表日を確認する |
| 書類を整えることに集中して勉強を止める | 必要科目の学習時間を予定表に確保する |
| 誰かの志望理由書をそのまま使う | 実際の経験から自分の問いと言葉で書く |
| 合格後の手続きは後で考える | 出願前に入学意思、費用、手続期限を確認する |

## 7. 条件を確認できたら先生に相談する

募集要項を読んだら、わからなかった条件をメモして先生に相談します。出願できそうかを確かめたうえで、書類と試験の準備を始めましょう。

### 出願を考えたときのチェックリスト

- [ ] 志望学部・学科の、対象年度の募集要項を確認した。
- [ ] 評定、履修科目、卒業時期、地域などの条件を確認した。
- [ ] 高校の推薦基準と校内選考の締切を先生に聞いた。
- [ ] 共通テストの有無、必要科目、配点、手続きを確認した。
- [ ] 推薦同士、総合型選抜、私立大学等との併願条件を確認した。
- [ ] 書類・小論文・面接等の内容と過去問を確認した。
- [ ] 大学への出願と学校への提出を予定表に入れた。
- [ ] 合格発表後の入学手続きと費用を家族で共有した。
- [ ] 不合格の場合に備えた一般選抜の準備も続けている。

先生との相談では校内選考と書類の提出日も確認してください。大学の締切より早いので予定表には両方を書いておきます。

大学別の確認例を見たい人は[京都府立大学の2027年度学校推薦型選抜の記事](https://wabi-lab.blog/posts/kyoto-prefectural-university-school-recommendation/)も参考にしてください。大学名が同じでも、受験年度や学科が違えば条件が変わり得ます。自分が受ける方式の情報を最後まで基準にしましょう。
