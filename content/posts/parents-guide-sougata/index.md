## 子どもが「総合型選抜を受けたい」と話したら

「勉強と両立できるのか」「どこまで親が手伝うべきか」。総合型選抜を考え始めた子どもを前に、戸惑うこともあると思います。

最初は志望先の募集要項を一緒に読んでみてください。必要な試験と出願日がわかると準備にどれくらい時間がかかるか話し合いやすくなります。

本人に任せたいのは志望理由を考えて書くこと。保護者が手伝いやすいのは費用や移動、手続期限の確認です。この記事ではその分担を考えます。

## 1. 何が評価されるかを親子で確かめる

### 1-1. 志望先の受入方針と試験内容を読む

総合型選抜では大学が示す**アドミッション・ポリシー（入学者受入れの方針）**に沿って、書類や面接、試験などを組み合わせて評価します。

偏差値だけでは出願や選考の条件はわかりません。必要な成績や資格、試験内容を募集要項で確かめましょう。「この大学で何を学びたいか」は本人の言葉で説明できるようにします。

### 1-2. 必要な教科の勉強も続ける

総合型選抜でも学力は確認されます。

小論文や口頭試問、共通テストなど、確認の方法は大学や方式によって違います。志望先で必要な科目と試験を調べてください。

| 学力確認の方法 | 具体例 |
|---------------|--------|
| 小論文・筆記試験 | テーマに対して論理的な文章を書く |
| 共通テスト利用 | 出願条件や得点換算に利用 |
| 資格・検定の活用 | 英検・数検などのスコアを加点 |
| 口頭試問 | 面接中に専門的な知識を問われる |

書類を仕上げる時間と教科の勉強時間を分けて予定を立てます。一般選抜も受ける可能性があるならその必要科目も確認しておきましょう。

### 1-3. 経験を振り返る手伝いをする

大会成績だけで出願を諦める前に必要な実績や資格を募集要項で確かめてみてください。

活動について話すときは結果に加えて、本人が考えたことや工夫したことを聞いてみてください。実績や資格が出願条件の方式もあるため、要件の確認は別に必要です。

> 「部長を頑張った」と聞いたら困った場面や自分で決めたことを尋ねてみましょう。話すうちに志望理由書の材料が見つかることがあります。

経験を整理するときの観点：

- **課題発見→行動→振り返り→成長**のサイクルが語れる
- 志望学部・学科の学びと **つながっている**- 「やらされた活動」ではなく**自分で意味を見出した活動**

「そのとき何を考えたの？」と尋ね、本人が経験を整理するのを手伝いましょう。

## 2. 書類の準備と受験勉強の予定を立てる

### 2-1. 出願前の面談や課題にも注意する

総合型選抜では出願前に面談や課題への取組が必要な場合もあります。以下は準備の目安です。実際の日程は志望先の要項で確認してください。

| 時期 | 総合型選抜 | 一般入試 |
|------|-----------|----------|
| 高3・4〜5月 | 志望校リサーチ・AP確認 | 受験科目の決定 |
| 高3・6〜7月 | **エントリー開始・志望理由書着手** | 模試・夏期講習準備 |
| 高3・8月 | **志望理由書完成・面接対策** | 夏期講習・追い込み |
| 高3・9月 | **出願** | 模試 |
| 高3・10〜11月 | **試験本番** | 推薦型選抜 |
| 高3・12月〜1月 | 合格／一般入試切り替え | **共通テスト直前** |

夏休みは教科の勉強に加えて、書類作成や面接練習の時間も必要になります。

> 書類作成も受験準備の一部です。何に時間を使っているかを聞いてから教科学習との配分を相談しましょう。

### 2-2. 合格後の勉強も本人と相談する

年内に結果が出る方式もありますが、共通テスト後まで選考が続く方式もあります。合格発表日と入学手続日を確認してください。

合格した後の予定も話しておきます。

**合格後に確認したいこと**

進路が決まった後は次のことを話しておきましょう。

- 大学から入学前課題が出ているか
- 専門分野の学習に向けて復習したい科目は何か
- 高校卒業までに読んだり調べたりしたいことはあるか

高校の授業を続けながら、入学後の勉強に向けた準備を本人と相談します。

### 2-3. 不合格の場合の受験予定も決めておく

一般選抜も考えるなら必要科目の勉強を続ける計画にします。推薦の準備が終わってから始めると時間が足りないことがあります。

1. 総合型選抜と一般選抜それぞれの締切を予定表に入れる。
2. 教科の勉強時間を確保して書類作成の予定を組む。
3. 結果発表の前後に必要な出願手続きを決めておく。

保護者は予定を全部管理するより本人が何を手伝ってほしいかを聞いてみてください。

## 3. 志望理由書や面接の準備を手伝う

### 3-1. 書く前に経験を聞いてみる

教科の勉強と違い、志望理由書には自分の経験から書く材料を集める時間も必要です。

志望理由書では関心を持ったきっかけや取り組んだ経験、大学で学びたい内容を説明します。思い出すのに時間がかかることもあります。

> 書けずに止まっているときは経験が足りないのか、大学の情報が足りないのか、言葉にするのが難しいのかを一緒に確かめてみましょう。

親がやってしまいがちなNG行動：

- 「こう書けばいい」と**答えを与えてしまう**- 「それだと弱い」と**否定だけする**- 「早く終わらせなさい」と**プレッシャーをかける**

望ましい関わり方：

- 「そのとき、どんな気持ちだったの？」と**エピソードを引き出す**- 「なんでそれが好きなの？」と**動機を深掘りする**- 完成した下書きを**真剣に読んで感想を伝える**

### 3-2. 面接の練習相手になる

面接の形式や質問内容は大学によって異なります。提出書類をもとに話す練習なら家庭でも取り組めます。

例えば次のような質問をしてみてください。

- 「書類に書いた活動で難しかったことを教えて」
- 「その方法を選んだ理由は何？」
- 「気になる社会問題についてどう考えている？」

本人が希望したら回答を一度聞いてみましょう。説明がわからなかった箇所を伝えるだけでも見直しの助けになります。

> 質問を続けすぎると話しにくくなることもあります。練習する時間と確認する点を先に決めておくと落ち着いて取り組めます。

### 3-3. 探究活動や課外活動がなぜ評価されるのか

探究や地域活動の経験を話すときは、自分が担った役割や考えたことを振り返ります。

経験を振り返るときの観点：

| 評価ポイント | 意味 |
|-------------|------|
| **課題発見力** | 当事者意識を持って問題を見つけられるか |
| **主体性** | 言われてではなく自分で動いたか |
| **振り返り・学び** | 経験から何を吸収したか |
| **継続性** | 思いつきではなく継続して取り組んできたか |

> 写真や活動記録を一緒に整理するのも手伝いの一つです。後から本人が経験を振り返るときに使えます。

## 4. 本人が書き、決められるように関わる

### 4-1. 注意する前に今の状況を聞く

準備の進み具合が見えないと「勉強しているの？」と聞きたくなるかもしれません。ただ、書類を考える時間も必要です。

| 気になること | 話しかけ方の例 |
| --- | --- |
| 勉強との両立 | 「今週は何の準備をしている？科目の勉強時間は取れそう？」 |
| 志望理由書の進み具合 | 「読んでほしくなったら声をかけてね」 |
| 先生への相談 | 「自分で相談できそう？必要な資料を一緒に探そうか」 |
| 出願手続き | 「学校に頼む書類はいつまでに必要？」 |

本人の説明を聞いてから、時間が足りない作業や手伝えることを相談しましょう。

### 4-2. 志望理由書は本人の言葉で書く

書類を読んでほしいと頼まれたら、まずは本人の文章のまま読んでみてください。

保護者の言葉で書き直すと、本人が面接で説明できない文章になることがあります。作成ルールも大学の指定を確認してください。

面接では書いた理由や経験の詳しい説明を求められることがあります。文章として整っていても本人の考えと違えば受け答えが難しくなります。

内容を決めて書くのは本人です。添削するときも、その言葉で本人の考えを表せているかを確かめます。

**保護者が手伝えること：**

- 誤字脱字を指摘する
- わかりにくかった部分を質問する
- 「この話、面接でも話せる？」と確認する

**本人に任せたいこと：**

- 志望理由の内容を決める
- 指摘を受けてどう書き直すか考える
- 自分の言葉で説明できる表現を選ぶ

### 4-3. アドバイスが必要かを先に聞く

話を聞いてほしいのか、具体的な意見がほしいのかを先に聞いてみてください。

話すうちに考えがまとまることもあります。途中で結論を急がず、いったん最後まで聞いてから質問します。

**話を聞くときに意識したいこと：**1.**途中で評価を挟まない**： 「いいね」「弱いね」という判断を挟まずに最後まで聞く
2. **質問で返す**： 「その経験、もっと詳しく聞かせて」と深掘りを促す
3. **受け止める**： 「それは大変だったね」と感情を受け止める

話を聞いた後は、わかったことと説明が足りなかった所を伝えます。

## 5. 併願・結果発表・入学費用を確認する

### 5-1. 次の受験先と出願条件を調べる

結果が出る前から、次に受ける可能性がある大学の日程と条件を調べておきます。合格したら入学を確約する方式では併願の扱いにも注意が必要です。

受験予定ごとに調べること：

| パターン | 対策 |
|---------|------|
| **第一志望に専願** | 不合格の場合に備えて必要な科目の勉強を続ける |
| **複数校を検討** | 双方の併願条件と入学確約、手続期限を確認する |
| **学校推薦型も検討** | 推薦を得られるかと校内締切、併願制限を事前に確認する |

> 結果が出てから慌てないよう、出願が必要になる日と準備する書類を先に共有しておきましょう。

### 5-2. 不合格だったときは本人の様子に合わせる

不合格をどう受け止めるかは人によって違います。すぐに次へ進みたい人もいれば、話すまで時間が必要な人もいます。本人の様子を見て声をかけてください。

**避けたい声のかけ方：**

- 「だから一般入試もちゃんとやっておけって言ったでしょ」
- 「総合型選抜はギャンブルだと思ってたよ」
- 「気持ちを切り替えて、すぐに一般入試の勉強始めなさい」
- 「原因は何だと思う？」（自責を促してしまう）

**声のかけ方の一例：**

> 「本当によく頑張ったね。結果は残念だったけど、あなたが挑戦したことは誇りに思う。ゆっくり休んで、また話しよう。」

すぐに原因を問い詰めるより、今は何をしてほしいかを聞いてみましょう。迫っている出願期限があれば、その事実は短く伝えて対応を相談します。

### 5-3. 入学金と手続期限を出願前に確認する

受験料だけでなく、合格後にいつ何を支払うかも確認しておきます。

入学手続きの期限は大学や方式によって違います。入学金と授業料の納付日が別の場合もあるため、要項に書かれた日付を確認してください。

特に**総合型選抜の結果が出た後も、他の入試の結果を待ちたい場合**は扱いを調べておきます。

合格後の入学が条件の方式では、他の結果を待って進学先を選べるとは限りません。併願できる方式でも納付済みの費用が返還されるかは別の問題です。大学の入学手続案内で扱いを確認しましょう。

**事前に確認すべき家計チェックリスト：**

- [ ] 志望校の入学金はいくらか
- [ ] 入学手続きの締め切りはいつか
- [ ] 入学費用の準備はできているか
- [ ] 第二志望校の入学金と締め切りとの競合はないか
- [ ] 滑り止め校の入学金をいったん納付するケースを想定しているか

## 親子で最初に確認すること

本人に任せることと保護者が手伝うことを一度話しておくと、毎日の確認が細かくなりすぎずに済みます。

- 志望理由や提出書類の内容は本人が考えて書く。
- 保護者は必要に応じて話を聞き、わかりにくい所を伝える。
- 出願費用・入学費用・転居の条件は家族で確認する。
- 結果が出る前に次の受験予定と締切を共有する。

まずは志望先の募集要項を開いて、試験日と手続期限を親子の予定表に入れてみてください。そのうえで本人が困っていることを聞くところから始めましょう。
